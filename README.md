
This repository is created for to practice of Terraform code to provision and manage AWS infrastructure.

Topics Covered

- VPC and Subnets
- EC2 Instances
- Security Groups
- IAM Users, Groups, Roles, and Policies
- S3 Buckets
- RDS
- Auto Scaling Groups (ASG)
- Application Load Balancer (ALB)


Purpose

To gain practical experience with Terraform by creating and managing AWS resources through Infrastructure as Code (IaC).
